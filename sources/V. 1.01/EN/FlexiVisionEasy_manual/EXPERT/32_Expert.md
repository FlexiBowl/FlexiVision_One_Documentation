# **What it is and When it is needed**

## What the Expert button is

The Expert button can be found on several FlexiVision One operational pages - for example in the Camera Setup and in the Clearances section of model creation. Clicking it opens an advanced mode that provides access to parameters and controls not visible in the standard wizard.

The Expert mode does not replace the wizard: it extends it. The correct workflow is always: first complete the standard procedure, then resort to Expert mode only if the results are unsatisfactory or if the application conditions explicitly require it.

```{note}
**Why it exists**

The standard wizard covers 90% of applications with optimised automatic parameters. The Expert mode exists for the remaining 10%: applications with particular lighting, parts with unusual visual features or non-standard installation conditions. It is not a tool for beginners, nor is it a shortcut for skipping the standard procedure.
```

---
## When is it needed?

### *Camera Setup - Expert Mode*

During Camera Setup, accessing the Expert mode allows you to:

- Choose the camera to work with.
- Set parameters such as Exposure, Brightness and Contrast.
- Select live view mode.
- Access other advanced camera features.

---

### *Model configuration - Expert mode*

During model training, the Expert mode allows you to:

- Apply a mask to the image to exclude irrelevant parts from the model.
- Adjust the scale and rotation of identification.
- Switch image polarity override on or off.
- Choose whether or not to use clutter scoring.
- Set the XY overlap.
- Access other advanced model identification features.
