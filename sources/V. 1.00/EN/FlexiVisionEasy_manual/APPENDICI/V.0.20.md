# V. 0.20

```{note}
This page refers to version **1.00** of this manual, which is compatible with **FlexiVision Studio v0.20**.
```

## **Improvements**

### License Management

- Added a robot-side check of the active license to ensure that picking functions are enabled only when a valid license is present.

## **Resolved Issues**

### Recipes

- Fixed an issue that prevented the **Enable Picking Robot** parameter from being saved correctly on the Application page.
- Fixed an issue that prevented the model name from being saved correctly within the recipe.

### PlugIn

- Fixed an issue with the plugin that occurred when the model name was deleted.
