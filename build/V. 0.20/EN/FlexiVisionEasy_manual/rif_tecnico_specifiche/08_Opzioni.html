Backlight#

The Backlight is a backlighting system positioned inside the FlexiBowl® table top that illuminates the part from below, creating a sharp contrast between the part profile and the luminous background. It is particularly effective for recognising shapes, contours and holes, regardless of the colour or surface finish of the part.

Backlight or Toplight?#

Warning

Impact on part identification

The choice between backlight and toplight significantly affects identification:

  • Backlight: Ideal for contours/shapes, pieces appear as dark silhouettes on a light background

  • Toplight: Required for identifying surface details, textures, internal features

Calibration, when using an ARS calibration grid, must be performed using the backlight illuminator and the toplight must be switched off if present.

When to use one or the other#

Illuminator

When to use it

Example

Toplight

Used when the component cannot be identified by the shape alone, but by the details on the object. It is primarily suitable for smooth, non-reflective surfaces, or surfaces with some kind of distinguishable markings.

Backlight

The backlight is mainly used when the object can be identified by its silhouette/shape or with transparent parts.

Typical use cases#

  • Screws, bolts, washers → Backlight

  • Pieces with print on top face, matt parts on dark surfaces → Toplight

  • Transparent or translucent parts → Backlight

  • Glossy pieces with reflections → Backlight

Lighting colour#

When to use each colour#

Colour / Wavelength

Recommended use

White

Used with transparent components. The cell needs to be shielded against any external light source and sunlight.

Red (630 nm)

Used for special metal components. Wavelength: 630 nm. The cell needs to be shielded against any external light source and sunlight.

Infrared (850 nm)

Preferred for most types of applications. It is not visible to the human eye. Wavelength: 850 nm. We recommend shielding the cell to avoid interference with sunlight.

For more information on Ambient Light Shielding, visit the Ambient Light Shielding section.

IR filter#

The IR filter is an optical accessory to be applied to the camera lens to block visible light while allowing only infrared radiation to pass through. This is only necessary if an IR illuminator (850 nm) is used: without a filter, the camera would receive both visible and infrared light, compromising contrast and identification quality.
